隐私政策 (Privacy Policy)

最后更新时间：2026年10月

欢迎使用 JsonMorph（以下简称“本插件”）。我们非常重视您的隐私。本隐私政策旨在说明我们在您使用本插件及购买 Pro 版本时，如何收集、使用和保护您的信息。

1. 我们收集的信息

为了提供核心功能并保护软件版权，我们可能会收集以下有限的信息：

  • 邮箱地址：当您购买 Pro 许可证时，支付平台（如 Creem 或 Paddle）会收集您的邮箱，用于发送订单确认和 License Key。
  • 机器码 (Machine ID)：VS Code 会生成一个匿名的机器环境标识符。当您激活 License 时，本插件会收集此标识符，用于绑定授权设备，防止 License 被盗用。
  • License Key：您在插件中输入的授权码，用于验证您的 Pro 权限。

2. 我们不收集的信息

  • 您的代码内容：本插件所有代码解析和转换操作都在您的本地 VS Code 环境中完成，我们绝不上传、截获或存储您正在转换的任何 JSON 文件内容或生成的代码。
  • 支付信息：我们不收集您的信用卡号、支付宝或微信支付账号。所有支付流程均由安全合规的第三方支付平台处理。

3. 信息的使用方式

我们收集的信息仅用于：

  • 验证您的 Pro 授权状态。
  • 协助处理授权迁移（如您更换了电脑）。
  • 向您发送与订单相关的重要通知。

4. 数据共享

我们不会向任何第三方出售、交易或转让您的个人信息。仅在与第三方支付平台（如 Creem）处理支付事务时共享必要的邮箱和订单信息。
