隐私政策 (Privacy Policy)

最后更新：2026年10月22日 · 生效日期：2026年10月22日

欢迎使用 JsonMorph Pro（以下简称“本插件”或“本服务”）。我们非常重视您的隐私。本隐私政策旨在说明我们在您使用本插件及购买 Pro 版本时，如何收集、使用、存储和保护您的信息。

本政策适用于 JsonMorph Pro 插件及相关官网购买页面。本政策不适用于第三方支付平台等由第三方独立运营的服务，这些服务适用其各自的隐私政策。

数据控制者：JsonMorph Pro 的个人开发者（以下简称“我们”），常驻中国天津市。我们目前以个人开发者身份运营本插件及相关购买页面。

联系方式：见本政策第 12 节。如您需要核实运营者身份或提出数据保护相关请求，可通过该邮箱与我们联系。

使用本服务即表示您同意本政策所述的信息处理方式。如果您不同意本政策，请停止使用本服务。

1. 我们收集的信息

为了提供核心功能、验证 Pro 授权并保护软件版权，我们可能会收集以下有限的信息：

  • 邮箱地址：当您购买 Pro 许可证时，支付平台（如 Creem 或 Paddle）会收集您的邮箱，并用于向我们传递订单信息，以便向您发送订单确认、License Key 和授权支持通知。
  • 机器码 / 设备标识符：插件运行环境可能生成匿名的机器或安装标识符（例如 VS Code 生成的机器标识符）。当您激活 License 时，本插件会将该标识符发送至授权验证服务器，用于绑定授权设备、防止 License 被盗用，并协助处理授权迁移。
  • License Key：您在插件中输入的授权码，用于向授权验证服务器验证您的 Pro 权限。
  • 技术日志：授权验证服务器可能自动记录 IP 地址、访问时间、请求类型、插件版本、操作系统类型和验证结果，用于安全防护、故障排查和防止滥用。

2. 我们不收集的信息

  • 您的代码内容：本插件当前版本的 JSON 解析、格式化和代码转换操作在您的本地环境中完成。我们不会上传、截获或存储您正在转换的 JSON 文件内容或生成的代码。
  • 支付信息：我们不收集您的信用卡号、支付宝或微信支付账号等支付凭证。所有支付流程均由安全合规的第三方支付平台处理。

3. 信息的使用方式

我们收集的信息仅用于以下目的：

  • 验证您的 Pro 授权状态；
  • 协助处理授权迁移，例如您更换电脑或重装系统；
  • 向您发送与订单、License Key 和授权相关的重要通知；
  • 保障授权验证服务的安全、稳定运行，排查故障和防止滥用；
  • 遵守适用的法律、税务和会计义务。

4. 数据共享与第三方服务

我们不会向任何第三方出售、交易或出租您的个人信息。我们仅在以下有限情形下共享必要信息：

  • 支付平台：当您购买 Pro 版本时，支付平台（如 Creem、Paddle 等）会独立处理您的支付和订单信息，并向我们传递必要的邮箱和订单状态，用于发放 License Key。支付平台是独立的个人信息控制者，其隐私政策请参见其官方网站。
  • 云服务与授权验证服务商：授权验证服务器可能由我们自建或委托云服务商托管。云服务商仅按我们的指示处理数据，并采取适当的安全措施。
  • 法律要求：如果我们收到合法的法律程序、法院命令或监管要求，可能在必要范围内披露信息。
  • 业务转让：如果本服务涉及合并、收购或资产转让，您的信息可能作为业务资产的一部分被转移，但我们会要求接收方继续遵守本政策。

5. 数据保留

我们仅在实现本政策所述目的所需的期限内保留您的信息，具体包括：

  • 邮箱和订单信息：在您的授权有效期间及授权终止后的合理期限内保留，用于授权支持、争议处理、税务和会计义务。
  • 机器码和 License 绑定信息：在授权有效期间保留；如您请求解绑或删除，我们会在合理期限内处理，但删除后相关 License 可能无法继续验证。
  • 服务器日志：在实现安全防护和故障排查所需的较短期限内保留，除非为调查安全事件或遵守法律要求需要更长时间。

6. 数据安全

我们采取合理的技术和组织措施保护您的信息，包括限制访问权限、使用加密传输和保存必要的安全日志。但请注意，互联网传输和存储不存在绝对安全，我们无法保证信息在任何情况下都不会被未经授权访问、披露或丢失。

7. 您的权利

根据适用法律，您可能有权访问、更正、删除您的个人信息，或限制、反对我们处理您的信息，并有权撤回同意。您可以通过本政策第 12 节的邮箱联系我们行使这些权利。

请注意，删除邮箱、机器码绑定或 License 记录可能导致我们无法验证您的 Pro 授权，从而影响您继续使用 Pro 功能。我们会在适用法律要求的期限内回应您的请求。

如果您位于欧洲经济区、英国、瑞士或其他提供数据保护权利的司法辖区，您还有权向当地数据保护监管机构投诉。

8. 国际数据传输

我们的支付平台、云服务商和授权验证服务可能位于您所在国家或地区以外。我们会要求相关服务提供方采取适当的安全措施，并在适用法律要求时采用合适的跨境传输机制。

9. 儿童隐私

本服务不面向未满 13 周岁的儿童。如果您位于欧洲经济区，未满 16 周岁的用户应在监护人同意下使用本服务。我们不会有意收集儿童的个人信息。如果我们发现误收集了儿童信息，会尽快删除。

10. Cookie 与类似技术

本插件当前版本不使用 Cookie 进行广告追踪，也未集成第三方广告 SDK、行为分析 SDK 或错误监控 SDK。插件运行环境（如 VS Code）自身的遥测设置、插件市场统计等，由相应平台按其隐私政策独立处理，我们无法控制其开关。

我们的授权验证服务可能记录必要的访问日志（如 IP 地址、访问时间、插件版本、验证结果），用于安全防护、故障排查和防止滥用。该等日志仅用于上述目的，不用于广告投放或用户画像。

官网可能由托管服务商记录必要的访问日志，并采用保障网站运行所必需的 Cookie。当前官网未接入第三方广告或行为分析工具。如未来引入相关功能，我们会更新本政策，并在适用法律要求时提供相应选择。

第三方支付平台的 Cookie 和追踪技术由其自行控制，请参阅其隐私政策。

11. 政策更新

我们可能不时更新本隐私政策。更新后的政策会发布在本页面，并更新“最后更新”日期。对于重大变更，我们可能通过插件内通知或邮件方式另行告知。继续使用本服务即表示您接受更新后的政策。
